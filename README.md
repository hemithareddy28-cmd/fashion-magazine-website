## ✨ Features

- Sticky navigation with smooth scroll and mobile hamburger menu
- Full-viewport hero banner with editorial typography
- Trend cards with hover animations and click-to-open popups
- Two-column editorial layout
- Responsive grid for runway and accessories
- Newsletter signup form
- Mobile-friendly layout

---

## 🔗 Dependencies (CDN — no install needed)

- Google Fonts — Playfair Display, Montserrat
- Font Awesome 6.5 — social icons

---

## 🚀 Run Locally

```bash
git clone https://github.com/hemithareddy28-cmd/fashion-magazine-website.git
cd fashion-magazine-website
open index.html
```
